# 🚀 Installation

Clone the repository.

```bash
git clone https://github.com/MaryamAmjad-Dev/Maryam-Amjad-Portfolio.git
```

Go to the project directory.

```bash
cd Maryam-Amjad-Portfolio
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
